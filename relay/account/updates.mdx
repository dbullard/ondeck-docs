Keeping Relay up to date helps ensure you have the latest fixes and compatibility improvements.

## What's new in Relay 1.3

- **Relay is free, and going open source.** Every feature that used to need Relay Pro is unlocked for everyone, with no license, subscription, or account needed. The source code moves to GitHub under the MIT license in Relay 2.0. See [Free & Support](/relay/account/license).
- **One Relay, with Preview features.** Beta and release are now one app and one update feed. Newer features live behind **Settings > Preview**. See [Preview features](/relay/account/beta-features).
- **Relay Account sign-in is being retired.** You no longer need an account, and magic-link sign-in will be retired in a future update.
- **Universal variables in automation, Live Mode canvas options, and secure LAN pairing.**

See the [full changelog](/relay/changelog#version-130) for the complete list.

## What's new in Relay 1.2.2

- **Setup Wizard:** A guided first-run wizard walks you through connecting services, choosing starter tiles, and creating your first dashboard.
- **Shared Values & Variables:** Define values once in the Variables window and use them across text inputs and automations.
- **Sennheiser Spectera monitoring:** Live state updates, pinned certificate trust, and authenticated connection tests.
- **Shure wireless overhaul:** A 10-segment mic meter, more accurate RF and battery readings, and self-healing connections.
- **Option-drag tile snapping:** Hold Option while dragging to snap a tile into a canvas region.
- **OSC automation** and **Close Home** improvements.

See the [full changelog](/relay/changelog#version-122) for the complete list, including Relay Mobile (Coming Soon) and Planning Center fixes.

## What's new in Relay 1.2

- **Synced Tabs:** Share one live, editable canvas across every Mac and iPad (Coming Soon) running Relay on your network, no cloud required.
- **Universal Automation:** Promote any automation graph to run across every tab that needs it, instead of just the tab it was built on.
- **Standard Console Actions:** Automation can directly trigger scene recall, mute, level, and pan on Behringer X32/M32, Yamaha DM7/Rivage, and Allen & Heath consoles — no third-party bridge required.
- **Tile Distribute Tools:** New distribute and grid-distribute controls, including one-click fill-window layouts.

See the [full changelog](/relay/changelog#version-12) for the complete list of improvements and bug fixes in 1.2, and for every earlier release.

### In-app update history

Relay keeps a **What's New** screen with your update history, shown from the home screen at any time. It also pops up automatically the first time you launch Relay after it updates itself, so you don't have to go looking for what changed.

### Beta-only features

Some features, like the **YouTube Live Stream Monitor** module, remain beta-only ahead of a stable release. Beta builds can expose newer features earlier than the main release feed — if you're testing a beta-only workflow, use the [beta changelog](/relay/beta-changelog) and the [beta features guide](/relay/account/beta-features) as the source of truth.

## Check for updates manually

1. Open Relay.
2. Choose `Relay > Check for Updates...`.
3. Follow the prompts if an update is available.

## Beta updates

Beta builds use the beta update feed and may receive newer features earlier, but should still be tested carefully before production use.

## Account-aware update notes

Relay `1.1.0` also improves entitlement refresh and account-backed licensing behavior. If an update finishes but Pro features still look locked, open `Relay > Settings` → <Icon icon="credit-card" /> **Subscription** and refresh both the direct license state and any signed-in Relay Account entitlements.

## Troubleshooting

If an update fails, make sure Relay is installed in the Applications folder and not still being run directly from a disk image.
