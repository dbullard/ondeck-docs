Modules are what give tiles meaning. Each module either displays information, pulls in live data, or provides a control you use during an event.

## Adding a module

1. Select a tile.
2. Open the add-module menu.
3. Choose a module.
4. Configure it in the inspector.

You can add more than one module to the same tile when the content belongs together visually.

## Beta and Preview modules

Some modules are still being refined and should be evaluated separately from the stable feature set.

- YouTube Live Stream Monitor, NDI Feed, and Sennheiser are marked beta
- Shure Overview, the multi-device wireless summary module, appears only when [Preview features](/relay/account/beta-features) are turned on

The standalone Shure module and Live Transcription are stable.

## Choosing one tile vs. multiple tiles

Use one tile when modules belong together visually. Use separate tiles when content should move, resize, or scale independently on the canvas.

## Free and beta notes

Every module is free in Relay 1.3 and later, with no license or subscription needed. Some modules carry beta status, especially around YouTube, wireless, and NDI workflows.
