The Variables window lets you define a value once and use it across text inputs and automations, instead of retyping it in each place. When the value changes, everywhere that uses it stays consistent.

## Where you can use them

- **Text inputs**, such as the [Text module](/dashboards/modules/utility#text).
- **Automations**, alongside the [variable utility nodes](/dashboards/nodes/utilities) in Automation View.

## Wireless telemetry variables

In Live Mode, Relay suggests wireless telemetry variables automatically. Suggestions are labeled with the channel names you saved for your devices, so a battery or RF value reads as "Pastor mic" instead of a raw device address.

See [Wireless devices](/integrations/wireless-devices) for how to add and name your devices.
