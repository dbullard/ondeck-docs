Relay 1.2.2 (build 62) Beta

New

  • Shared Values & Variables — A new Variables window lets you define values once and use them across text inputs. Values are grouped by source, with plus controls for adding from each source, and the window stays above Relay while you work.
  • Wireless variables — Suggested wireless telemetry variables are created automatically in live mode, labeled with your saved channel names. You can refresh names from the Variables window.
  • Insert variables anywhere — Variables can be inserted into the focused editor, and insertion controls now sit on each row. Shared variables can be deleted from the window.
  • 10-segment mic meter — The Shure mic meter now has 10 segments with a -60 dBFS floor for finer readings on quiet signals.

Fixes

  • Transcription profanity filter — The filter now catches inflected words and already-censored text, and stays applied.
  • ProPresenter slide numbers — Slide numbers now come from ProPresenter's slide index, and disabled slides are counted correctly in group ranges.
  • Variables window — Variables stay scoped to Relay, the window no longer reopens on launch, and its shortcut no longer collides with the system screenshot shortcut.
