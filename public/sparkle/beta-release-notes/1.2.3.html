Relay v1.2.3 Beta

New Features

  • Universal Variables in Automation: Variables can now be integrated directly into automation rules and conditions, enabling more dynamic and context-aware workflows.
  • Expanded Variables Catalog: New variable types and linked computer person variables for richer automation scenarios and enhanced device synchronization.
  • Linked Computer Sharing: Improved support for sharing and synchronizing variables across linked computers with better pairing and connection management.
  • Live Mode Canvas Settings: New configurable options for canvas fit and full-screen behavior to customize your Live Mode layouts.

Fixes & Improvements

  • Sync & Mirror Pairing Reliability: Fixed trust and connection recovery issues for more stable device pairing and data synchronization.
